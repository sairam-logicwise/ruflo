A quote that visibly improves over time is persuasive. A quote that was quietly wrong and never revisited is not. Once tasks carry real actuals, a separate, prerequisite need, add a command that reports the quoted range. Report the real actual too, and whether the actual fell inside the quoted range. Report this per task and in aggregate — the hit rate. Show how that hit rate trends over time. A stakeholder should see the estimator actually getting better, not just take that claim on faith. This is the only real feedback signal on whether the estimator works at all.
